# Range 60 · 码头靶场

Range 60 是一款用 Three.js 和 Vite 构建的第一人称浏览器靶场。每局 60 秒，击碎一个移动悬浮靶得 1 分。你可以开镜减轻后坐力，也可以观察集装箱上的掉漆、地面的灰尘和水洼里的波纹，判断上一发偏向了哪里。

## 本地运行

准备 Node.js 22.12 或更新版本、npm，以及支持 WebGL 2 和鼠标锁定的桌面浏览器。

```sh
git clone https://github.com/lhf2018/fps.git
cd fps
npm ci
npm run dev
```

打开终端输出的本地地址，点击「开始训练」。浏览器锁定鼠标后开始计时。

## 键鼠操作

| 输入 | 动作 |
| --- | --- |
| 鼠标移动 | 转动视角 |
| W A S D 或方向键 | 移动 |
| 鼠标左键 | 单击射击，按住连发 |
| 按住鼠标右键 | 开镜，松开回到腰射 |
| R | 换弹，每匣 30 发 |
| 空格 | 跳跃 |
| 按住 C 或 Ctrl | 蹲下 |
| Esc | 暂停并释放鼠标，点击「继续训练」返回本局 |

## 回合与纪录

命中后，靶子会碎裂并在新的靶位出现。计时归零时画面冻结，结算面板显示得分、命中数、实际开火数和命中率。零发回合的命中率显示为「—」。

个人最佳保存在当前浏览器的本地存储中。每局结束时可以看到是否刷新纪录，以及与之前最佳成绩的分差。点击「开始下一局」并成功锁定鼠标后，计时、弹药和靶位会重置。

## 构建与预览

```sh
npm run build
npx vite preview
```

构建产物位于 `dist/`，可部署到静态站点的根路径。场景材质的来源见[素材说明](public/materials/SOURCES.txt)。
